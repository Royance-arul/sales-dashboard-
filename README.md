# Sales Dashboard

## Project Description
This is a basic Next.js website built with Atomic Design principles. It displays sales data for 2022, 2023, and 2024 using Recharts for visualization. Data is mocked from Kaggle-inspired samples but integrates with a public API for real data. Features include:
- Switchable chart types (bar, line, pie).
- Custom sales threshold filter.
- API fetch for dynamic data.

Tech stack: Next.js 15, TypeScript, Tailwind CSS, Recharts.

## Setup Instructions
1. Clone the repo: `git clone <your-repo-url>`
2. Install dependencies: `npm install`
3. Run dev server: `npm run dev`
4. Visit http://localhost:3000/dashboard
